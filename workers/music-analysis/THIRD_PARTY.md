# Dependencies and permitted fixtures

The local image uses Python 3.12, librosa 0.11.0 (ISC), NumPy (BSD), SciPy (BSD),
psycopg (LGPL-3.0), and their pinned dependencies in requirements.lock.
Licenses and metadata are installed inside the Python distributions.

Primary references:
- https://github.com/librosa/librosa/blob/0.11.0/LICENSE.md
- https://librosa.org/doc/0.11.0/generated/librosa.feature.chroma_cqt.html
- https://librosa.org/doc/0.11.0/generated/librosa.beat.beat_track.html
- https://ffmpeg.org/legal.html
- https://sources.debian.org/src/ffmpeg/

The measured Debian FFmpeg 5.1.9 package enables GPL components. `ffmpeg -L`
reports GPL-2.0-or-later; do not describe this binary as LGPL-only. It is used
unmodified as a separate local executable. No image/binary is published by this
repository task. Review distribution obligations before distributing an image.
Debian package copyright/source information is available in the image and at the
Debian source URL above. No third-party model weights or paid API are used.

Benchmark guitar: FreePats recorded notes/montages, CC0, with provenance in
apps/web/public/audio/guitar. Other reference signals are generated by spike.py
and owned by this project. They are test signals, not the product guitar timbre.
No private recordings, lyrics, streaming downloads or benchmark audio are committed.
