# Como usar os prompts com Codex

1. Copie este pacote para o repositório StrumLab.
2. Escolha **somente a fase atual** e forneça o respectivo arquivo ao Codex.
3. O agente deve ler `AGENTS.md`, `README.md`, `docs/10-roadmap.md`, `docs/12-decisoes.md` e documentos específicos da fase.
4. Primeiro apresentar plano e confirmar apenas decisões bloqueantes ainda não resolvidas. Reutilizar autorizações e decisões já registradas. Não executar serviços remotos sem permissão.
5. Ao final, conferir testes reais, commits/arquivos alterados, pendências e documentação atualizada.
6. Não permitir que Codex marque como concluída uma fase não validada.

A ordem das fases é a da **v1.1**; não usar numeração antiga da v0.2.
